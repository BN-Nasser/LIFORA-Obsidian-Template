# Goals & Milestones

Create goals freely and add milestones only when you choose. Goal records are stored as individual Markdown files in `Goals/`, and this section is included in the hidden portable `data` backup.

- Milestone-based goals calculate progress from weighted milestones.
- Target-based goals calculate progress from your current and target values.
- Statuses: Planned, Active, Paused, Completed, Archived.
