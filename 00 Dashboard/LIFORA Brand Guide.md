# LIFORA — Brand Guidelines

**YOUR LIFE. IN FLOW.**

Personal Life & Learning System

## Brand foundation

LIFORA is a personal operating space for organizing everyday life, learning, reading, reflection, and continuous growth.

The product should feel calm, precise, premium, and personal. It should support the user's workflow rather than impose one.

## Design principles

1. Use the LIFORA symbol with the wordmark in brand-level surfaces.
2. Keep the daily cover dynamic and preserve each weekday's existing visual identity.
3. Use consistent SVG icons with restrained glow; avoid emoji as interface icons.
4. Use clear hierarchy, generous spacing, soft borders, and subtle depth.
5. Keep the interface English-first.
6. Use short, action-oriented labels.
7. Do not add mandatory learning plans, unnecessary notifications, or duplicate navigation.
8. Preserve the user's existing folder structure, file paths, links, and content.

## Typography

- Interface and body: Inter, with Segoe UI/system sans-serif fallbacks.
- Code and technical content: JetBrains Mono, Cascadia Code, or Consolas fallback.
- Wordmark: uppercase with generous letter spacing.
- Headings: strong but restrained; avoid oversized decorative text.

## Product architecture

- Home: central dashboard and entry point.
- Daily Journal: dated pages, daily identity, reflections, and daily actions.
- Planning: weekly and periodic planning.
- Learning: courses, Quran, and language learning.
- Library: books and knowledge notes.
- Templates & Resources: reusable material and reference assets.
- Settings: personalization, backups, and workspace preferences.

## Compatibility and data preservation

The current Obsidian vault remains the storage layer. Internal folder names, plugin IDs, note paths, frontmatter tags, and existing links are retained for compatibility. LIFORA is the product-facing brand layer.
