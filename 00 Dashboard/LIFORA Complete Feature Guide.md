# LIFORA — Complete Feature Guide

**YOUR LIFE. IN FLOW.**

This guide lists the integrated features in LIFORA v2.1.0. The vault remains the storage layer; existing user content and legacy paths are retained.

## 1. Home Dashboard

The original LIFORA Home layout is restored without a redesign. Only the product name and logo/icon are rebranded to LIFORA.

- Opens as the default workspace when the vault starts.
- Keeps the current dynamic daily cover and weekday identity.
- Shows live summary cards for courses, books, languages, and knowledge notes.
- Displays real root folders as section cards using the original section-card layout.
- Opens each selected folder in the main workspace.
- Shows recent activity and configurable home widgets.
- Includes the requested global floating Create button without changing the original Home layout.

## 2. Smart Workspace Explorer

- Clicking a folder card opens its real contents in the main workspace.
- Clicking a folder in the native Obsidian File Explorer also opens the workspace view.
- Displays real subfolders and real files, not simulated cards.
- Provides breadcrumbs and parent-folder navigation.
- Supports Grid and List modes.
- Supports live search and sorting by name, modification date, and file type.
- Shows folder/file counts and modification dates.
- Supports real folder creation and Markdown note creation.
- Supports per-folder background, text, and accent colors.
- Refreshes to reflect changes made through Obsidian's native File Explorer.
- Keeps system dashboard files out of the user-facing folder listing.

## 3. Floating Create Actions

### Home-level Create
- New folder: choose an existing destination folder, then create a real folder.
- New note: choose a destination folder, create a Markdown note, and open it.
- New course.
- Add book.
- Add language.
- Create a Quran wird.
- Open today's journal.

### Folder-level Create
- New folder inside the currently open folder.
- New note inside the currently open folder.
- Refresh the current folder view.
- Menu closes on outside click or Escape.

## 4. Daily Journal & Planning

- Preserves the original daily note files and links.
- Preserves the year / month / day folder structure.
- Preserves weekday-specific covers and daily visual identities.
- Reuses the current daily identity across Home and section dashboards.
- Supports daily, weekly, monthly, quarterly, and yearly review workflows where present.
- The Yesterday / This Week / Tomorrow navigation strip remains removed.

## 5. Courses

- Each course is created inside its own real folder.
- Each course uses one main Course Dashboard / study file; no fixed lecture/assignment subfolder structure is imposed.
- The user adds their own topics.
- The user manually marks each topic complete.
- Course progress is calculated from completed topics.
- Supports course status, platform, instructor, dates, course URL, and custom course color.
- Supports course editing and topic management.

## 6. Books Library

- Three shelves: Currently Reading, Unread, and Read.
- Reading progress is shown only for Currently Reading books.
- Stores total page count and user-updated current page.
- Calculates reading progress from current page / total pages.
- Supports user-created book category folders.
- Supports book file uploads and custom cover images.
- Each book opens its own dedicated book workspace.

## 7. Quran Journey

- Includes all 114 Surahs and their ayah counts.
- Tracks memorization, reading, and revision independently for each Surah.
- Allows recording completed ayah ranges.
- Supports multiple customizable daily wirds.
- Wirds can be daily, on selected weekdays, or one-time.
- Supports targets, units, time, date ranges, optional Surah/ayah ranges, notes, enable/pause, and completion logging.
- The interface controls are English; Arabic Surah names remain available alongside transliteration.

## 8. Language Learning Studio

- Supports CEFR levels A1, A2, B1, B2, C1, and C2.
- A1 is the default starting level.
- The user can select a higher level directly when appropriate.
- Supports target levels and completed levels.
- Supports user-managed learning topics and manual completion.
- Supports vocabulary, mastery tracking, study sessions, and study-time summaries.

## 9. Writing Studio Pro

The writing toolbar appears when editing ordinary Markdown notes, not on dashboard-only pages.

- Headings, bold, italic, underline, strikethrough, and highlight.
- Text size, text color, and text background color.
- Inline code and syntax-highlighted code blocks.
- Inline LaTeX math and block LaTeX math.
- Bulleted lists, numbered lists, checklists, and block quotes.
- Colored title/callout boxes and tables.
- Horizontal dividers, links, and reusable templates.
- Insert images, resize selected images, and attach files.
- Record and insert voice notes.
- Insert date and time.
- Word and character count.
- Undo / redo and toolbar collapse.

## 10. Appearance, Navigation & Backup

- LIFORA Dark Luxury theme with Champagne Gold accent.
- Custom LIFORA Symbol, Wordmark, and App Icon SVG assets.
- English-first product interface.
- SVG interface icons with restrained glow.
- Left sidebar remains the real folder tree; dashboard files are not intended as navigation items.
- Backup Center and existing backup workflow are retained.
- Existing plugin IDs and data paths are preserved for compatibility.

## Data preservation guarantee

No existing daily note, course, book, Quran progress record, language record, attachment, or user-created folder is intentionally deleted or migrated by this release. Legacy LIFORA dashboard paths remain as compatibility entry points.
