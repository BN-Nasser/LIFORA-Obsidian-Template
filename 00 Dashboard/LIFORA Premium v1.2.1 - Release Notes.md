# LIFORA Premium v1.2.1 — Navigator Update

## Added
- LIFORA Navigator companion plugin.
- Home icon in Obsidian's left ribbon; it opens the original Welcome dashboard.
- LIFORA Hub icon in the ribbon; it opens the complete navigation directory.
- Navigation commands for Daily Journal, Courses, Reviews, Knowledge, Templates, Calendar, AI settings, Templater, and Dataview refresh.
- LIFORA Hub page as a central navigation directory.
- Knowledge Library and Templates Library index pages.

## Preserved
- The official LIFORA Plugin source and settings are unchanged.
- The Journals calendar remains available as its own pane.
- The original Welcome cover, seven weekday banner identities, daily notes, templates, media, and existing plugin configuration are preserved.
- The Home action opens a Markdown editor tab instead of replacing the active calendar side pane.
