# LIFORA Premium v1.2.0 — Release Notes

## Added
- Courses Library with native, nested Obsidian folders.
- Courses Home dashboard with a Dataview course register.
- Course Dashboard Template, available through Templater's enabled template list.
- Shared course resource folders for references, cheat sheets, practice files, links, and certificates.
- Daily Journal Home with current-period navigation and recent/high-rated journal lists.
- Structured Focus, Schedule, and Reflection sections in newly generated daily notes.
- Reviews Hub for current weekly, monthly, quarterly, and yearly notes.
- Premium additive CSS snippet for dashboard styling and folder color accents.
- Iconic folder icons and color assignments for the LIFORA sections and Courses tree.

## Preserved
- The original Welcome cover and its DashboardBanner.gif reference.
- The seven weekday banner images and the existing `Daily Banner Config.md` logic.
- Existing daily, weekly, monthly, quarterly, and yearly templates and AI components, except for the additive Daily sections.
- Existing notes, links, media, scripts, plugin files, and plugin configuration, except for the explicitly noted path corrections and added settings.

## Notes
- Existing daily notes are not rewritten. The new Focus, Schedule, and Reflection blocks appear in daily notes created after this update.
- Course folders are real folders in the Obsidian File Explorer. Create additional nested folders there and assign their colors using Iconic's folder actions.
- The course dashboard register requires the already-installed Dataview plugin.
- No external network service is required for the new folder structure or dashboards.
